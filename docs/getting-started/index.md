# Getting started

Use this section to install Captcha Security Shield and understand the minimum steps
needed before configuring a CAPTCHA provider.

## Recommended sequence

1. Install and activate Captcha Security Shield.
2. Create credentials in the selected provider dashboard.
3. Enter those credentials in **Settings → Captcha Security Shield**.
4. Select the provider globally or for an individual form.
5. Test the protected form in a private browser session.
